# Host check

At installation and at every start-up, EmbedForge compares this computer with its profile.

| Profile | Requirements |
|---|---|
| A — laptop or PC | 4 cores / 8 threads with AVX2, 16 GB RAM (32 GB recommended), 60 GB free SSD space, display 1920×1080 (usable at 1366×768) |
| B — Raspberry Pi 5 | 8 GB RAM (16 GB recommended), NVMe recommended (A2 microSD of 128 GB minimum), active cooling, official 27 W supply |

Each shortfall is shown with its consequence, for example which performance targets may be
missed.

**Supported systems:**
- Windows 10 22H2 and Windows 11;
- Ubuntu Desktop LTS 22.04 or later;
- Raspberry Pi OS 64-bit Bookworm or later, on a Pi 5.
