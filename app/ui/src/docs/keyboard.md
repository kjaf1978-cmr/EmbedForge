# Keyboard reference

Every function can be reached from the keyboard. The **command palette** (**Ctrl+Shift+P**)
lists all commands, with their shortcuts.

| Keys | Action |
|---|---|
| Ctrl+Shift+P | Command palette |
| Ctrl+1 | Focus the navigator |
| Ctrl+2 | Focus the workspace |
| Ctrl+3 | Focus the help pane |
| F6 / Shift+F6 | Next / previous pane |
| Ctrl+B | Show or hide the navigator |
| Ctrl+Alt+B | Show or hide the help pane |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+= / Ctrl+- / Ctrl+0 | Larger / smaller / default font |
| Ctrl+Shift+L | Switch light and dark theme |
| Ctrl+L | Library browsers |
| Ctrl+Shift+D | Self-diagnosis |
| F1 | Help for the current view |
| Escape | Close the palette or an overlay |

**Tab** and **Shift+Tab** move between the controls of a view.
